# 异环乐器模拟器

一款桌面端《异环》风格乐器软件（作者：林羽empty）：**练习模式**（三排 36 键虚拟键盘 + MIDI 自动演奏，模拟器内发声）+ **演奏模式**（把 MIDI 乐谱作为真实按键弹进游戏，支持后台注入）。

基于 **Electron 33 + Web Audio + @tonejs/midi + koffi(Win32 FFI)**，离线运行，绿色免安装或 NSIS 安装包两种交付形态。

---

## 一、功能总览

### 虚拟键盘（手动演奏）
- 三排 × 12 键，音域 **C3 – B5（MIDI 48–83）**，简谱 `1 #1 2 b3 3 4 #4 5 #5 6 b7 7`，高音区/低音区带八度点标记；
- 物理键盘（`e.code` 映射，免受输入法/大小写影响）：

  | 音区 | 自然音 | Shift（#1/#4/#5） | Ctrl（b3/b7） |
  |---|---|---|---|
  | 低音 | `Z X C V B N M` → 48/50/52/53/55/57/59 | `Shift+Z / V / B` → 49/54/56 | `Ctrl+C / M` → 51/58 |
  | 中音 | `A S D F G H J` → 60…71 | `Shift+A / F / G` → 61/66/68 | `Ctrl+D / J` → 63/70 |
  | 高音 | `Q W E R T Y U` → 72…83 | `Shift+Q / R / T` → 73/78/80 | `Ctrl+E / U` → 75/82 |

- 鼠标点击演奏；**按住 Shift 点 1/4/5 位、按住 Ctrl 点 3/7 位**触发对应变化音（与键盘规则一致）；
- 同键连击叠音不切断旧音；`e.repeat` 防抖；窗口失焦自动抬键防粘音；`Esc` 紧急全静音。

### MIDI 自动演奏
- 选择本地 `.mid / .midi / .rmi`（自动剥离 RIFF/RMID 封装）；
- **总音量**：滑杆 0–1 映射到 0–2.2 增益，末端接**透明限制器**（仅接近削波时起效，不影响平时音量）；自动演奏的 MIDI 力度做了提升映射（典型 0.5–0.8 → 0.78–0.87），与手动演奏（0.92）响度一致且保留强弱层次；
- **选轨**：全部轨道（默认）/ 主旋律（自动，排除通道 9 后取音符最多的轨道）/ 自定义索引（如 `0,2`）；
- **热切换保护**：播放中变更轨道 / 超域 / 转调时自动"短暂停启"（暂停→应用→约 130ms 后续播），避免新旧调度交错导致爆音或无声；
- **丝滑变速 / 丝滑换音色**：速度与音色不做任何停顿——练习模式变速原地重锚（正在响的声部自然延续，无重复触发）；演奏模式变速通过 worker 热重定基替换剩余调度（游戏内不断音）；换音色后台加载、就绪即切，旧声部在旧音色上自然衰减；
- **转调**：±36 半音，播放中实时生效（保持进度）；
- **超域处理**（超出 48–83 的音符）：
  - `fold` 就近八度折叠（默认，一个不丢；只移动到最近的音区边界，保持声部间相对音区——低音 Bass 不会被抛到高音区）；
  - `shift` 最优八度平移（枚举 ±3 个八度，取"范围内音符最多、整体最贴中心"的平移量，残余截断，推荐多声部）；
  - `cut` 直接截断；
  - 全部轨道模式自动排除打击乐通道（ch9，鼓件编号不是音高，混入会变怪音）；
- **防碰撞**：同键 10ms 内重复触发自动去重；最大 32 声部，超出偷最旧；同键重叠音按声部栈管理，灯效引用计数复位；
- **调度**：双时钟方案 —— 25ms lookahead 把未来 ~160ms 音符按 `AudioContext.currentTime` 精确排程（声音采样级准），rAF 消费灯效队列（视觉同步）；
- **进度条**可拖拽/点击任意位置起播；**变速** 0.25–3.0× 播放中实时生效；暂停/恢复/停止齐备；
- **全局热键**：`F8` 播放/暂停、`F9` 停止（Electron `globalShortcut`，窗口失焦也可用）；注册失败自动退化为窗口内热键。

### 跟弹教学（练习模式 · 实验性）
设置面板「教学」下拉选择，选择后点播放即进入教学（琴键自动静音，按键不发声）：

- **跟弹 · 等待**：时间轴驻留在当前和弦处，琴键金色脉动高亮"现在按什么"、虚线高亮"下一组"（用户弹奏**正常发声**，只是不自动弹奏）；瀑布流音符条上直接标注按键名（密集谱面按车道自动去堆叠，不糊屏）；按对判定**宽松**（和弦内不限顺序、按错无惩罚），按对的音符条变绿并继续；全部完成显示命中统计；
- **弹奏回声**：手动弹奏（练习/教学任意时刻）时，瀑布流判定线升起属于你的音符长条——**按住越长条越长**，松手后整条上移流出，1.75 秒后消失；回声条颜色可在设置面板「回声」取色器中调整；
- **跟弹 · 同步**：原曲正常播放不阻塞，跟随指示弹奏，±0.6s 内按对变绿；
- 教学中拖动进度条：结束本次教学并定位到新位置（下次播放从该处重新开始教学）；Esc/停止退出教学并恢复发声。

### 键盘谱导出
「导出键盘谱」按钮按当前设置（轨道/转调/超域）生成整曲按键谱 txt：**一行一小节**（谱面紧凑），格式 `小节 │ 拍位:按键`（如 `1 │ 1:A 2:A 3:G 4:G`，`1.5:A+C` = 第 2 拍后半拍同时按 A+C），组合键 `⇧A`/`↓E`，每 4 小节留空行，含键位图例；系统保存对话框导出（浏览器模式自动降级为下载）。

### 演奏模式（游戏内自动弹奏）
迁移自 [MaaNTE](D:\JOY\MaaNTE-win-x86_64-v1.6.0-MXU) auto_piano 的实证方案，把 MIDI 谱面作为按键弹进《异环》游戏内的钢琴：

- **后台注入（默认，推荐）**：`PostMessageW` 直发 `WM_KEYDOWN/UP` 到游戏窗口——**做别的事时游戏照弹**；每个和弦前发送 `WM_ACTIVATE` 激活消息（50ms 超时保护）骗过游戏的失焦检查（MaaNTE 同款技巧）；
- **前台模拟**：`keybd_event` 真实键盘输入（先发 ALT 键解除前台锁定再 `SetForegroundWindow`），兼容性兜底；
- 按键细节与 MaaNTE 完全一致：**专用左 Shift(0xA0)/左 Ctrl(0xA2)**（游戏区分左右修饰键，用错会跑调）、lParam 带硬件扫描码（无符号 32 位零扩展，与 Python ctypes 行为一致）、和弦按修饰键分组短按（默认 8ms 按住，可调 2–60ms）；
- **窗口识别适配 UE 引擎**：自动检测优先"标题含 异环/NTE 且类名 UnrealWindow"的窗口（MaaNTE 实证标题为 `NTE  ` / `异环  `，尾部双空格）；窗口下拉框显示每个窗口的**类名**，方便确认选中的是游戏主窗口而非启动器；
- **「诊断」按钮**：一键检查目标窗口（类名/可见/最小化/是否前台/PostMessage 投递结果/**双方进程权限**）并给出建议——游戏无反应时先用它定位；
- **权限（UIPI）**：游戏若以管理员运行，Windows 会拦截普通权限进程发送的按键——面板会显示当前权限状态并提供**「以管理员重启」**一键提权（游戏管理员运行时必须同样提权）；
- **演奏内容与练习模式逐音一致**：演奏模式完全复用练习模式的事件管线（同选轨/转调/踏板/超域处理，同 48–83 目标音域），仅在发送按键前把结果 +12 平移到游戏键位——模拟器 Z/A/Q 三排与游戏三排物理键一一对应，同一琴位同一键；超域 fold（就近八度折叠）/shift/cut 与练习模式完全同源；本模拟器琴键在演奏模式下**仅作演示**（点亮对应键位 + 瀑布流联动），不发声；
- **窗口高度自适应内容**：启动与切换模式后窗口自动贴合页面高度（受屏幕工作区限制；**最大化/全屏时自动跳过**，不会被系统还原；带防抖，不会反复微调），练习/演奏模式均无滚动条；
- **权限护栏**：未以管理员运行时，后台注入会被**弹窗**拦截（可选：以管理员重启 / 改用前台模式 / 取消；前台模拟不受限，走倒计时弹窗引导切换到游戏窗口）；
- **提权重启**：新实例带 `--wait-lock` 等待旧实例退出释放单实例锁（最多 20 秒）后接管启动——修复 UAC 确认后"只关不开"的竞态；
- **演奏中参数锁定**：演奏进行时轨道、超域、窗口、模式、**速度、转调**等全部选项自动锁定（演奏中修改会打乱调度），仅保留 进度条 与 播放/暂停/停止；
- **进度条（重写架构）**：worker 引擎是位置的唯一权威；拖动 = 「原地重定基」命令——会话不中断、不重启、不弹窗：播放中无缝跳（前台后台一致）、暂停中改锚点（恢复即从新位置继续）、停止后记录位置；界面时钟 = worker 最近位置 + 本机外推（每 100ms 校准，抖动 ≤30ms 不可见）；每次 seek/play 携带自增纪元 id，旧会话的迟到事件从数据结构上不可能污染状态；
- **前台失焦自停**：前台模拟演奏中，游戏窗口一旦失去焦点立即自动停止（防止真实按键打进别的窗口）；
- **新手引导**：首次打开自动开始练习模式教程；首次切到演奏模式自动开始演奏模式教程（聚焦讲解、逐步下一步）；顶栏「? 教程」可随时重看当前模式教程；
- 使用步骤：打开游戏（**窗口化、不要最小化**）→ 切到演奏模式 → 自动检测窗口（或从列表选）→ **测试按键**（游戏里应响起 C-E-G；无反应点「诊断」）→ 设倒计时 → 播放；速度/转调/选轨/超域/进度条与练习模式完全共用（演奏中轨道/超域锁定）；
- **调度运行在独立 worker 线程**（perf-worker.js）：和弦时序精确且完全不占主进程——界面零卡顿；暂停/恢复/停止经 worker 消息通道，响应 <20ms；渲染层对高频音符事件做了日志节流。

> ⚠️ 游戏自动化可能违反用户协议，请自行评估账号风险；本工具仅供学习交流。
> koffi 为原生依赖，已配置自动解包（asar.unpacked）；若引擎加载失败会自动降级（仅练习模式可用）并提示。
> 游戏无反应排查顺序：①窗口化且未最小化 → ②「诊断」确认选中的是 UnrealWindow 类名的窗口 → ③「测试按键」→ ④切换前台/后台模式 → ⑤增大按键时长。

### 其他
- **默认音色**：明亮钢琴（可随时切换，选择会被记住）；
- **多音色（13 套，全音域 88 采样 A0–C8）**：钢琴类 —— 古典钢琴 / 明亮钢琴（FluidR3、FatBoy 渲染）/ 明亮原声钢琴 / 电钢琴；色彩类 —— 弦乐合奏 / 竖琴 / 马林巴 / 颤音琴 / 钢片琴 / 尼龙吉他 / 长笛 / 人声合唱 / 八音盒。启动即扫描，加音色只需丢文件夹（见下文）；
- **曲库（收藏夹）**：导入的 MIDI 自动**复制一份**到应用数据目录（`userData/library`，浏览器调试模式存 IndexedDB），源文件删除/移动不影响曲库；支持分类标签（自由命名 + 筛选）、排序（最近导入/名称/时长/音符数）、网格/列表双布局、内联确认删除；卡片点击即载入演奏；
- **内置曲目**：首次启动自动把「天真的橡皮」「朋友的酒」「瞬間交响曲」三首加入曲库（打「内置」标签）；播种仅一次，删除后不会重生；
- **音高保真引擎**：自动演奏超出 36 键映射范围的音符，用"最近采样 + playbackRate 变调"播放**真实音高**（采样器标准做法）——fold/shift 只影响视觉键位映射，不再扭曲音准；手动演奏仍在 36 键内 1:1 无变调；
- **延音踏板（CC64）**：自动演奏解析 MIDI 踏板记号，踩板期间松键的音延续到抬板（参考 MaaNTE auto_piano 的算法）——大量乐谱的连奏全靠它；
- **可调延音（手动）**：0–5000ms 滑杆，松键后声音延续相应时长再温和收尾；
- **瀑布流可视化**：Synthesia 式落音面板（36 车道按低/中/高分组，半音车道为暗色墨条，音符按轨道着色、主旋律玫瑰红），触底粒子迸发 + 车道闪光；**底部简谱标注条**（自然音清晰、半音淡色、被弹到的音随轨道色点亮）；手动演奏同样有粒子反馈；实时日志改为可切换页签；
- 实时日志（音名 + 键位 + 来源标签）与统计（总音符/映射后/截断/当前声部数）；
- 设置（速度/转调/选轨/超域/音量/延音/音色/提示开关/底部页签/曲库视图）本地持久化；
- **滑杆即调即弹**：调整速度/音量/延音/进度后无需点击空白处，焦点自动归还，直接就能演奏。

### 音频如何被打包并正确加载（extraResources 原理）

`package.json` 的 `build.extraResources` 把 `assets/` 复制到安装目录的 **`resources/assets`**（ASAR 包外），主进程按两种环境解析路径：

- **开发态**：`app://root/assets/...` → 映射到项目根的 `assets/`；
- **打包态**：`renderer` 等代码打进 `resources/app.asar`；`assets` 读 `process.resourcesPath/assets`。

主进程注册了特权协议 `app://`（`standard + supportFetchAPI`），渲染层统一用相对路径 `../assets/audio/<音色>/<midi>.mp3` 发起 `fetch → decodeAudioData`——既绕开 `file://` 的 CORS 限制，又保证开发/打包两态路径一致。协议处理器用 `fs.readFileSync` 返回内容（fs 对 asar 内路径透明），并带正确的 Content-Type。

> 若 rcedit 报 `Unable to commit changes`（常见于 Defender 实时扫描刚复制的大 exe），重跑一次打包即可；该错误只影响 exe 版本信息，不影响功能。

## 五、添加新音色（多音色扩展）

1. 准备逐键采样 mp3，按 **MIDI 音高编号**命名：`48.mp3 … 83.mp3`（推荐全音域 `21.mp3 … 108.mp3` 即 A0–C8，越密变调越小）；
2. 放入 `assets/audio/<音色id>/`，并写一个 `manifest.json`：`{"name": "显示名", "min": 21, "max": 108}`；
3. 重启应用，音色下拉框会自动出现（Electron 由主进程扫描目录；浏览器模式读取 `instruments.json`，可运行 `node tools/make-demo-midi.mjs` 重建该索引）。

下载工具同样可用：

```bash
node tools/fetch-audio.mjs download grand bright upright epiano musicbox strings harp marimba vibraphone celesta guitar flute choir
#   ↑ gleitz/midi-js-soundfonts 全音域（MusyngKite/FatBoy），已存在的文件自动跳过（可续传/升级）
node tools/fetch-audio.mjs legacy <老项目audio目录>  # 按映射表迁移老项目 a/b 编号音频
```

- Electron：`%APPDATA%/yihuan-piano-zcode/library/`（乐曲副本 + `library.json` 索引）；卸载重装不丢（除非手动删该目录）；
- 浏览器调试模式：IndexedDB（浏览器配置文件内）。

|---|---|
| `electron . --selftest --midipath=<mid绝对路径>` + `--enable-logging` | 冒烟自检：IPC 音色扫描 / IPC 读文件 / app:// 音频 / 解析，结果输出到控制台 `[selftest]` |

## 七、避坑指南

**音频相关**
1. **音频加载失败 / 个别键无声**：看日志里"缺失采样"提示；确认 `assets/audio/<音色>/` 文件名是 `48.mp3…83.mp3` 且未损坏（>4KB）。开发态可用浏览器模式快速定位（F12 看网络面板）。
2. **无声但界面正常**：先按 `Esc` 再按琴键（解除可能的系统静音/独占）；检查音量滑杆；Electron 下 AudioContext 在首次交互后才会出声（首次点击/按键即解锁）。
3. **快速连击卡顿**：本引擎每音符独立声部+压缩器防削波，若仍卡顿，降低同时按住的键数或关掉其他占用音频设备的应用。

**MIDI 相关**
4. **解析失败/乱码**：
   - 某些 `.mid` 实为 **RMI**（RIFF 容器）——已自动剥壳；剥壳失败会明确报错；
   - 轨道名乱码：**UTF-8** 命名已自动修复；GBK/Shift-JIS 等编码无通用解法，显示原样但不影响演奏；
   - 0 字节或截断文件会得到可读错误提示。
5. **melody 自动选轨不理想**：打击乐通道（ch9）已排除；若主旋律人声在 ch9 或音符数少于伴奏，改用"自定义索引"。
6. **多声部按键碰撞**：fold 模式下不同声部折叠到同键属正常现象（叠音发声）；嫌浑浊可换 `shift` 模式。

**打包/环境相关**
7. **npm install 慢**：`.npmrc` 已内置 npmmirror 镜像（electron 二进制与 builder 工具链）；若提示 "Unknown project config" 警告可忽略。
8. **下载音色失败**：`tools/fetch-audio.mjs` 内置 直连→ghfast.top→gh-proxy.com 三级回退；全失败时按"添加新音色"一节手动放置文件。
9. **SmartScreen 提示**：未签名 exe 首次运行会弹"Windows 已保护你的电脑"，点"更多信息→仍要运行"。
10. **杀软误报**：Electron 应用常见误报，加入白名单即可。
